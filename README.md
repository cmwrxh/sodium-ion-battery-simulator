# Sodium-Ion Battery Simulator (2026 Edition)

Open-source Python tool to model sodium-ion vs lithium-ion batteries for grid storage in the energy transition.

Focus: Compare key metrics post-2026 breakthroughs (e.g. CATL Naxtra at ~175 Wh/kg, approaching LFP parity).

**Why now?** Sodium-ion offers cheaper, abundant materials, better safety/cold performance for stationary storage amid lithium constraints.

## Key Metrics (2026 snapshot)
- Sodium-ion (e.g. CATL Naxtra): ~165–175 Wh/kg, 5,000–10,000+ cycles, ~$70–100/kWh (scaling to lower)
- Lithium-ion LFP: ~150–210 Wh/kg, 3,000–6,000 cycles, ~$80–100/kWh
